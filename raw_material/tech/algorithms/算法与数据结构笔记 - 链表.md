# 算法与数据结构笔记 - 链表

LeetCode 2 [Add Two Numbers](https://leetcode.com/problems/add-two-numbers/)
记录下是否要进位，然后就是L1，L2同时链表遍历，再遍历位数多的，最后看还有没进位

LeetCode [287. Find the Duplicate Number](https://leetcode.com/problems/find-the-duplicate-number/)
这个有点技巧，将nums[index]作为下一个数据的指针，判断链表有没环，找到环的起始点。怎么找有没环 - 快慢指针，等到快的和慢的相同时，将一个置为起始点，然后再遍历到相同。

LeetCode [86. Partition List](https://leetcode.com/problems/partition-list/)
记录两个链表，大于和小于，记得有dummy head，最后的时候将p1.next = p2head.next; 然后返回p1head.next

LeetCode [23. Merge k Sorted Lists](https://leetcode.com/problems/merge-k-sorted-lists/)
用PriorityQueue, PriorityQueue<ListNode> q = new PriorityQueue<>(list.length, (a,b)->(a.val-b.val));
之后就是拿出q中node，放入新的List，然后将node.next放入q

LeetCode [160. Intersection of Two Linked Lists](https://leetcode.com/problems/intersection-of-two-linked-lists/)
分别遍历a,b,然后将b接在a，a接在b，最后找到相同的，就是相交点

LeetCode [206. Reverse Linked List](https://leetcode.com/problems/reverse-linked-list/)
递归解法  
last = reverse（head.next）;
head.next.next = head;
head.next = null;
return last;

LeetCode [24. Swap Nodes in Pairs](https://leetcode.com/problems/swap-nodes-in-pairs/)
prev, first, second
first.next = second.next;
second.next = first;
prev.next = second;
prev = first;

LeetCode [234. Palindrome Linked List](https://leetcode.com/problems/palindrome-linked-list/)
left
right
left = head;
visit(head.next);

public void visit(ListNode node) {
	right = node;
	if (left!=right) {
		isPalidrome = false;
	}
	left = left.next;
}
