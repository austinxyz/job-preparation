# Workbook Part 1: Identity, Story, Language, Culture, Scope

This workbook is the hands-on companion to the Hiring Physics Playbook. Transforms passive reading into active skill-building. One-time foundation sections (1-5) require 4-6 hours total.

## Section 1: Identity OS Builder

### 1.1 Leadership Thesis
Complete: "I am a leader who..."

Self-check criteria:
- Is this specific to me, not generic leadership platitudes?
- Would a colleague who knows me well recognize this as accurate?
- Does this differentiate me from other leaders at my level?

### 1.2 Career Through-Line
Step 1: List last 3-4 roles + key choice or theme in each.
Step 2: Complete: "The thread connecting my career is..."

### 1.3 Signature Strengths
Identify 2-3 things distinctively good at — not just competent, genuinely differentiated.
For each: Strength → Evidence (specific example proving this).

### 1.4 Growth Edges
1-2 areas actively developing. Frame constructively — not weaknesses, but current focus areas.
For each: Growth Edge → What I'm doing to develop this.

### 1.5 Emotional Stance
Complete: "I want people to experience me as..."
List 3 specific behaviors that support this stance.

### 1.6 Executive Narrative Draft
Template structure:
```
[Identity Statement] I'm a [type of leader] who [distinctive approach].
[Scope Marker] Currently, I [role] at [company], where I [scope].
[Operating Principles] I believe [principle]. My approach is [method].
[Signature Lesson] The most important thing I've learned is [insight].
[Current Focus] Right now, I'm focused on [priority]. That's what drew me to [connection].
```
**Timing check: read aloud, target 75-90 seconds.**

## Section 2: Story Library Builder

### Story Categories (aim for at least one in each)
1. Major decision with incomplete information
2. Cross-functional conflict or alignment
3. Significant failure and what you learned
4. Organizational change you led
5. Technical leadership or architecture decision
6. Team building or performance management
7. Influencing without authority
8. Managing up or executive alignment
9. Crisis or high-pressure delivery
10. Strategic tradeoff or prioritization

### Story Template Schema
For each story, document:

| Field | Content |
|-------|---------|
| **One-Sentence Summary** | |
| **The Decision I Made** | |
| **Tradeoffs I Navigated** | |
| **Principle That Guided Me** | |
| **Business Impact** | |
| **Key Learning** | |

**This schema is the actionable version of the Decision-First Framework applied to story catalog building.** The "Decision I Made" and "Tradeoffs I Navigated" fields force you to articulate executive-level thinking before you get in the room.

Build 10-15 stories total across the 10 categories.

## Section 3: Language Pattern Analyzer

### Self-Recording Exercise
Record yourself answering 3 questions (2 min each):
1. "Tell me about your biggest accomplishment in your current role."
2. "Describe a difficult decision you made recently."
3. "Tell me about a conflict you navigated."

### Pattern Tally (per question)
| Pattern | Q1 | Q2 | Q3 |
|---------|----|----|-----|
| Times said "we" instead of "I" | | | |
| Times described tasks/activities | | | |
| Times articulated a decision | | | |
| Times named a tradeoff explicitly | | | |
| Times connected to business impact | | | |
| Times articulated a principle | | | |

**Target ratios:** "I" >> "we"; decisions >> tasks; tradeoffs ≥ 1 per answer; business impact ≥ 1 per answer.

### Before/After Upgrade Practice
Take phrases from the recording and practice upgrading them:

| What I Said (Tactical) | Upgraded Version (Executive) |
|------------------------|------------------------------|
| "We decided to..." | "I made the call to..." |
| "We had to fix..." | "I determined that the core issue was..." |
| "My team delivered..." | "I was accountable for..." |

## Section 5: Scope Ladder Climber

### Target Scope Level by Role
- Staff/Principal IC: Project + System level
- Senior Manager: Project + System level
- Director: System level primarily, Organization level examples
- VP: System + Organization level
- SVP/CXO: Organization level primarily

### Accomplishment Upgrade Template
For each major accomplishment, write all four scope versions:

| Scope | Description |
|-------|-------------|
| **TASK** | What I personally did |
| **PROJECT** | What my team delivered |
| **SYSTEM** | What capability I built |
| **ORG** | How I changed the company |

**Practice:** Write 4-5 accomplishments at all four levels. Identify which level to lead with for your target role. Practice that version until it's fluent.

**Key insight from this exercise:** The same work can legitimately be described at any scope level. The question is which level is *appropriate* for the role. If you're interviewing for VP and delivering Project-scope answers, you're signaling Director-level thinking.
